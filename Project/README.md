# نظام إدارة محطات الوقود ⛽

نظام متكامل لإدارة محطات الوقود والمبيعات مبني باستخدام Streamlit و MySQL.

## المميزات الرئيسية ✨

### 🔐 نظام المصادقة
- واجهة تسجيل دخول محسنة مع تصميم عصري
- دعم أنواع مستخدمين متعددة (مدير، مالك، موظف)
- نظام إعادة تعيين كلمة المرور
- حماية من محاولات الدخول المتكررة

### 📊 لوحة التحكم
- إحصائيات شاملة للمبيعات والعملاء
- مراقبة المخزون والتنبيهات
- رسوم بيانية تفاعلية
- نظرة عامة على أداء النظام

### ⚙️ نظام الإدارة
- إدارة محطات الوقود
- إدارة الموظفين والعملاء
- إدارة الفواتير والخزانات
- إدارة المالكين

### 📈 التقارير والإحصائيات
- تقارير المبيعات التفصيلية
- تحليل استهلاك الوقود
- تقارير أداء العملاء
- تقارير أداء الموظفين

### 🔧 الإدارة المتقدمة
- إدارة المستخدمين والصلاحيات
- إعدادات النظام وقاعدة البيانات
- إدارة أسعار الوقود
- سجلات النظام

## متطلبات التشغيل 📋

### المتطلبات الأساسية
- Python 3.8 أو أحدث
- MySQL Server
- متصفح ويب حديث

### المكتبات المطلوبة
```bash
pip install -r requirements.txt
```

## إعداد قاعدة البيانات 🗄️

1. قم بإنشاء قاعدة بيانات جديدة في MySQL
2. قم بتشغيل ملف `Create_database.py` لإنشاء الجداول المطلوبة
3. تأكد من تحديث معلومات الاتصال في `core/database.py`

## تشغيل النظام 🚀

```bash
cd Project
streamlit run main_app.py
```

## أنواع المستخدمين 👥

### 1. المدير (Admin)
- صلاحيات كاملة على النظام
- إدارة المستخدمين والإعدادات
- الوصول لجميع التقارير والإحصائيات

### 2. المالك (Owner)
- إدارة محطات الوقود
- مراقبة المبيعات والأرباح
- الوصول للتقارير المالية

### 3. الموظف (Employee)
- إدارة الفواتير والعملاء
- مراقبة المخزون
- صلاحيات محدودة حسب المهام

## المميزات التقنية 🛠️

- **واجهة مستخدم تفاعلية**: تصميم عصري ومتجاوب
- **أمان عالي**: تشفير كلمات المرور وحماية من الهجمات
- **قاعدة بيانات قوية**: MySQL مع دعم العمليات المعقدة
- **تقارير متقدمة**: رسوم بيانية وإحصائيات مفصلة
- **أداء محسن**: تحسينات في الأداء والاستجابة
