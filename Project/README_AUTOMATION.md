# نظام إدارة محطات الوقود - مع الاستشعار الآلي

## 🚀 المميزات الجديدة

### 🤖 الاستشعار الآلي
- **تكامل مع أجهزة الاستشعار الحقيقية**: PTS2 و ATG APIs
- **قراءات تلقائية**: قراءة مستويات الوقود كل ساعة
- **تسوية آلية**: حساب ديون الموظفين تلقائياً كل 7.5 ساعات
- **معالجة الأخطاء**: الرجوع للقراءات المحاكاة عند فشل الأجهزة

### 📊 إدارة ديون الموظفين
- **إضافة ديون جديدة**: تسجيل ديون الموظفين مع الحساب التلقائي
- **عرض الديون المعلقة**: متابعة جميع الديون غير المسددة
- **تسوية الديون**: تحديث حالة الديون عند السداد
- **البحث بالموظف**: عرض ديون موظف محدد مع الإحصائيات

## 🛠️ التثبيت والتشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إنشاء قاعدة البيانات
```bash
python Create_database.py
```

### 3. تشغيل النظام مع الاستشعار الآلي
```bash
# Windows
START_AUTOMATION.bat

# أو يدوياً
streamlit run main_app_automation.py --server.port 8502
```

## 🔧 إعدادات الاستشعار

### إعدادات PTS2 API (افتراضية - تجريبية)
```python
pts2_config = {
    'base_url': 'https://api.pts2-sensor.com/v1',
    'api_key': 'demo_pts2_key_12345',
    'timeout': 30,
    'auth_type': 'api_key'
}
```

### إعدادات ATG API (افتراضية - تجريبية)
```python
atg_config = {
    'base_url': 'https://api.atg-sensor.com/v1',
    'api_key': 'demo_atg_key_67890',
    'timeout': 30,
    'auth_type': 'api_key'
}
```

### ربط أجهزة الاستشعار بالخزانات
```python
sensor_mappings = {
    'PTS2': {
        'sensor_001': 'TANK_001',
        'sensor_002': 'TANK_002'
    },
    'ATG': {
        'atg_001': 'TANK_003'
    }
}
```

## 📋 استخدام النظام

### 1. تسجيل الدخول
- استخدم بيانات الدخول المعتادة

### 2. مراقبة النظام الآلي
- في الصفحة الرئيسية ستظهر حالة النظام الآلي
- أخضر = النظام يعمل
- أصفر = تحذير (قراءات محاكاة)

### 3. إدارة ديون الموظفين
- اذهب إلى **الإدارة > الموظفون**
- اختر تبويب **💰 ديون الموظفين**
- استخدم التبويبات الفرعية للعمليات المختلفة

## 🔄 العمليات الآلية

### قراءة الاستشعار (كل ساعة)
1. محاولة قراءة من PTS2 API
2. عند الفشل، محاولة ATG API
3. عند الفشل في كليهما، استخدام قراءات محاكاة
4. حفظ القراءة في قاعدة البيانات

### التسوية الآلية (كل 7.5 ساعات)
1. حساب الفرق في مستويات الوقود
2. تحديد كمية الوقود المباع
3. حساب المبلغ المستحق
4. إنشاء سجل دين للموظف المسؤول

## 📊 مراقبة النظام

### سجلات النظام
- جميع العمليات مسجلة في ملفات السجل
- مراقبة حالة الاتصال بأجهزة الاستشعار
- تتبع نجاح/فشل العمليات الآلية

### لوحة التحكم
- عرض حالة النظام الآلي
- إحصائيات الديون والتسويات
- تنبيهات الأخطاء والمشاكل

## 🛠️ التخصيص

### تغيير إعدادات API
```python
from core.sensor_api import initialize_sensor_api

# إعدادات مخصصة
pts2_config = {
    'base_url': 'https://your-pts2-api.com/v1',
    'api_key': 'your_actual_api_key',
    'timeout': 60
}

initialize_sensor_api(pts2_config=pts2_config)
```

### تغيير تردد التسوية
```python
from core.automation import start_scheduler
from apscheduler.triggers.interval import IntervalTrigger

# تغيير لكل 4 ساعات
trigger = IntervalTrigger(hours=4)
scheduler.add_job(perform_daily_reconciliation, trigger)
```

## 🔧 استكشاف الأخطاء

### مشاكل شائعة

1. **فشل الاتصال بـ API**
   - تحقق من صحة URL و API key
   - تأكد من اتصال الإنترنت
   - راجع سجلات النظام للتفاصيل

2. **عدم عمل التسوية الآلية**
   - تأكد من وجود موظفين مُعينين للمضخات
   - تحقق من وجود قراءات سابقة
   - راجع سجلات قاعدة البيانات

3. **قراءات خاطئة**
   - تحقق من ربط أجهزة الاستشعار بالخزانات الصحيحة
   - راجع إعدادات API
   - قارن مع القراءات اليدوية

## 📞 الدعم

للمساعدة أو الإبلاغ عن مشاكل:
1. راجع سجلات النظام في مجلد logs/
2. تحقق من إعدادات قاعدة البيانات
3. تأكد من تثبيت جميع المتطلبات
