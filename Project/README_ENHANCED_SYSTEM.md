# 🚀 نظام إدارة محطات الوقود - النسخة المحسنة

## 📋 نظرة عامة
هذا النظام المحسن يوفر إدارة شاملة لمحطات الوقود مع إمكانيات متقدمة للتعيينات والربط بين الموظفين والمضخات والخزانات.

## ✨ المميزات الجديدة

### 🔗 نظام التعيينات المتقدم
- **ربط الموظفين بالمضخات**: تعيين موظفين محددين لكل مضخة
- **ربط المضخات بالخزانات**: ربط كل مضخة بخزان وقود محدد
- **إدارة التعيينات**: إضافة، تعديل، وحذف التعيينات بسهولة
- **عرض التعيينات**: عرض جميع التعيينات الحالية مع التفاصيل

### 🏭 إدارة المحطات المحسنة
- **إدارة المحطات**: إضافة وتعديل وحذف المحطات
- **إدارة المضخات**: إدارة شاملة للمضخات مع ربطها بالخزانات والموظفين
- **إدارة الخزانات**: إدارة خزانات الوقود مع مراقبة المخزون
- **التقارير المحسنة**: تقارير تفصيلية للمحطات والمضخات والخزانات

### 👥 إدارة الموظفين المحسنة
- **إضافة موظفين**: نموذج شامل لإضافة الموظفين
- **عرض الموظفين**: قائمة بجميع الموظفين مع تفاصيلهم
- **التقارير**: تقارير مفصلة عن الموظفين حسب المحطة

## 🚀 كيفية التشغيل

### الطريقة الأولى: ملف التشغيل التلقائي
1. انقر نقرة مزدوجة على `START_ENHANCED_SYSTEM.bat`
2. سيتم فتح النظام تلقائياً في المتصفح

### الطريقة الثانية: التشغيل اليدوي
```bash
# إنشاء قاعدة البيانات
python Create_database.py

# تشغيل النظام
streamlit run main_app_permissions_fixed.py
```

## 📊 قاعدة البيانات المحسنة

### الجداول الجديدة:
- **Assignments**: جدول التعيينات والربط
- **Fuel_Pumps**: جدول المضخات المحسن
- **Fuel_Tanks**: جدول الخزانات المحسن
- **Petrol_Stations**: جدول المحطات المحسن

### العلاقات:
- المحطة ← المضخات ← الخزانات
- المحطة ← الموظفون
- المضخة ← الموظف (تعيين)
- المضخة ← الخزان (ربط)

## 🎯 كيفية الاستخدام

### 1. تسجيل الدخول
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

### 2. الوصول لصفحة الإدارة
- انقر على "⚙️ الإدارة" في الشريط الجانبي

### 3. استخدام نظام التعيينات
- انقر على "🔗 إدارة التعيينات"
- يمكنك:
  - إضافة تعيينات جديدة
  - تعديل التعيينات الحالية
  - حذف التعيينات
  - عرض جميع التعيينات

### 4. إدارة المحطات والمضخات
- انقر على "🏭 إدارة المحطات"
- يمكنك إدارة:
  - المحطات (إضافة، تعديل، حذف)
  - المضخات (مع ربطها بالخزانات والموظفين)
  - الخزانات (مع مراقبة المخزون)
