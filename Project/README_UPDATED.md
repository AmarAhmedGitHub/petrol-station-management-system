# نظام إدارة محطات الوقود ⛽

نظام متكامل لإدارة محطات الوقود والمبيعات مع واجهة مستخدم عصرية ومتجاوبة.

## ✨ المميزات الرئيسية

### 🎨 واجهة مستخدم محسنة
- **واجهة تسجيل دخول بسيطة** - بدون شريط جانبي، header واحد فقط
- **تصميم عصري ومتجاوب** - يعمل على جميع الأجهزة
- **انتقال سلس** - من تسجيل الدخول للتطبيق الرئيسي
- **ألوان متدرجة جذابة** - مع تأثيرات بصرية جميلة

### 🔐 نظام المصادقة
- دعم أنواع مستخدمين متعددة (مدير، موظف، مالك)
- حماية من محاولات الدخول المتكررة
- إدارة الجلسات والحالة
- نظام إعادة تعيين كلمة المرور

### 📊 لوحة التحكم
- إحصائيات شاملة للمبيعات والعملاء
- مراقبة المخزون والتنبيهات
- رسوم بيانية تفاعلية باستخدام matplotlib
- نظرة عامة على أداء النظام

### ⚙️ نظام الإدارة
- إدارة محطات الوقود (CRUD كامل)
- إدارة الموظفين والعملاء
- إدارة الفواتير والمبيعات
- إدارة الخزانات والمخزون

### 📈 التقارير والإحصائيات
- تقارير مبيعات مع التصفية بالتاريخ
- تحليل استهلاك الوقود حسب النوع
- تقارير أداء العملاء والموظفين
- رسوم بيانية تفاعلية بدون أخطاء

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية
- Python 3.8 أو أحدث
- MySQL Server
- متصفح ويب حديث

### خطوات التثبيت

1. **استنساخ المشروع**
   ```bash
   cd Project
   ```

2. **تثبيت المتطلبات**
   ```bash
   pip install -r requirements.txt
   ```

3. **إعداد قاعدة البيانات**
   ```bash
   python Create_database.py
   ```

4. **تشغيل النظام**
   ```bash
   streamlit run main_app_login_fixed.py
   ```

## 🎯 كيفية الاستخدام

### 1. تسجيل الدخول
- افتح المتصفح واذهب إلى `http://localhost:8501`
- ستجد واجهة تسجيل دخول بسيطة ومرتبة
- أدخل بيانات تسجيل الدخول الصحيحة

### 2. التنقل في النظام
- بعد تسجيل الدخول، سيظهر الشريط الجانبي
- اختر القسم المطلوب من القائمة الجانبية
- استخدم أزرار التنقل للانتقال بين الأقسام

### 3. المميزات المتاحة
- **لوحة التحكم**: عرض الإحصائيات والرسوم البيانية
- **الإدارة**: إدارة المحطات والموظفين والعملاء
- **التقارير**: تقارير مفصلة مع رسوم بيانية
- **الإدارة المتقدمة**: إعدادات النظام والمستخدمين

## 🔧 استكشاف الأخطاء

### مشاكل شائعة وحلولها:

1. **خطأ في قاعدة البيانات**
   - تأكد من تشغيل MySQL
   - تحقق من بيانات الاتصال في `core/database.py`

2. **مشاكل في الرسوم البيانية**
   - استخدم الملفات المصححة (`main_reports_fixed.py`)
   - تأكد من تثبيت matplotlib: `pip install matplotlib`

3. **مشاكل في واجهة تسجيل الدخول**
   - استخدم `main_app_login_fixed.py` للحصول على أفضل تجربة
